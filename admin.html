Đăng nhập quản trị

Dùng mã truy cập GitHub (token) của tài khoản quản lý kho website.

Cách tạo mã truy cập (làm một lần)
  1. Đăng nhập GitHub bằng tài khoản quản lý kho website.
  2. Mở github.com/settings/personal-access-tokens/new.
  3. Đặt tên (ví dụ “Quan tri website truong”), chọn thời hạn.
  4. Repository access → Only select repositories → chọn kho .
  5. Permissions → Repository permissions → Contents → Read and write.
  6. Bấm Generate token, chép mã và dán vào ô trên. Không gửi mã này cho người khác.

Người phụ trách khác muốn quản trị: thêm tài khoản GitHub của họ vào kho (Settings → Collaborators), rồi họ tự tạo mã riêng.
